# Lontra Labs — website

Source for the Lontra Labs one-page site.

A single static `index.html` (inline CSS, no build step). Edit it directly and push to `main`; GitHub Pages redeploys automatically.

## Hosting

Served by GitHub Pages from `main` (root). The custom domain `lontralabs.io` is registered through Cloudflare Registrar; DNS points at GitHub Pages.

## Local preview

Open `index.html` in a browser, or run any static server from the repo root.
